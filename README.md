

**Project: Interactive Calculator & Unit Converter**

I developed a menu-driven command-line application using Python. The project includes basic arithmetic operations such as addition, subtraction, multiplication, and division.

I also implemented the following conversions:

1. **Currency Conversion:** INR to USD and USD to INR.
2. **Distance Conversion:** Kilometers to Miles and Miles to Kilometers.
3. **Temperature Conversion:** Celsius to Fahrenheit and Fahrenheit to Celsius.

The program uses Python functions, conditional statements, while loops, and exception handling to validate user input and prevent errors. It continues running until the user selects the Exit option.

**Technologies Used:** Python Programming
